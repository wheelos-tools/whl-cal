# LiDAR-IMU 分段标定实施计划

依据 `docs/lidar2imu.md` 及其子文档，分段指连续数据窗口或独立采集
session；不把外参各自由度视为相互解耦。仅对同一安装配置联合标定。
保持 extraction → algorithm → evaluation 分离，质量评价不改写 GRIL。

## P0：冻结基线和数据

1. 核对采集身份、topic、时钟、坐标、ring、点时间、缺口以及输入和二进制
   哈希；保留原始 canonical 输入、配置及基线产物。
2. 以 corrected-IMU 0827 为工作回归 fixture，完整运行原生 GRIL 三次，
   与 frozen reference 分别比较；不把它当物理真值或将 raw IMU 结果混入。
3. 不通过的输入及 no-result 保留原因，不降低 GRIL 的充分性门限。

## P1：分段独立验证

1. 按时钟重置和缺口分割，结合静止、直线加减速、左右转和场景结构人工
   选取互补窗口；独立采集留作最终 holdout。窗口边界及所有上下文不得
   跨训练/验证划分，不能重复计量重叠样本。
2. 从冻结 canonical 输入提取完整扫描和窗口内 IMU，保留原始值、来源、
   哈希、绝对时间及质量报告；检查扫描末点的 IMU 覆盖和段内缺口。
   GRIL 的启动、前段丢弃和充分性需求必须另行检查；片段过短应报告
   no-result，不修改求解器。
3. 每段完整运行前端和 batch 三次，记录失败、轨迹、结果及时间 profile；
   对照同一输入的全段基线，分析前端重复性与窗口差异，不挑最好结果。

## P2：单段研究算法

P0 数据合格且 P1 基线可解释后，先用合成真值和退化样例验证坐标、
时间符号、SE(3) 模型及残差 Jacobian；再实现单段连续时间候选，与 GRIL
使用相同输入和 holdout。不能用优化收敛代替可观测性或物理精度。

## P3：多段联合

P2 通过后，同一安装配置共享 LiDAR→IMU 外参；每段独立轨迹、世界系和
bias，时钟参数按真实时钟架构共享或独立。比较单段、互补段和联合结果，
之后再研究基于边缘化信息的自动选段；不可重复累加相同观测。

## 验证与退出条件

- 报告数据和含先验的边缘化信息、弱方向、先验敏感性及各参数状态。
  平面运动不足以自行确定垂直杆臂；高度因子需要独立可靠的高度测量。
- 分别检查旋转、x/y/z 平移、时间、三次完整运行、留段及独立物理 holdout。
  研究重复性参考：0.2°、3 cm、1 ms；不是准确度证明或自动发布条件。
- 查看分段轨迹、时间相关、前端一致性及相同区域去畸变点云；同源 INS
  和配置 TF 不是外参真值。保留所有运行和失败，不覆盖基线。
- 当前 corrected-IMU 0827 的物理结果 rejected，native/frozen 旋转等价门
  未通过；在消除这些阻塞之前，结果只能用于研究和诊断。

## 2026-11-15 放宽研究比较门限后的执行

- 根据用户要求，本轮参考结果的**平移比较门限**从 3 cm 改为 5 cm；
  原 3 cm 报告保留，GRIL 内部充分性门限、旋转 0.2° 和时间 1 ms 比较
  门限不变。三次完整基线平移差均低于 5 cm，但其中两次旋转仍高于
  0.2°，因此不能宣称完整 frozen-reference 等价。
- 58 秒训练段三次均未出结果，GRIL 日志最后显示 Z 轴进度约 15%；
  此进度来自前端 Hessian 的轴分配启发式，不是物理可观测性的证明。
- 为定位所需数据长度，额外运行约 130.16 秒的探索窗口三次，均得到
  结果；窗口内最大重复差为旋转 0.143°、平移 1.43 cm、时间 0.316 ms。
  它与全段数据高度重叠，且与此前同采集保留段重叠约 72.15 秒，不能
  用该保留段验证这个新窗口。窗口按已知完整运行的充分性时刻事后选取，
  不构成独立或预注册比较。
- 此探索窗口与完整运行对应结果的最大平移差约 4.12 cm；时间 profile
  的各窗口偏移仍不一致。GRIL 在两个窗口都于约 126.8 秒处达到充分性并
  提前进入 batch，故这不是独立运动数据的比较。完整报告和原始产物在
  `outputs/gril/segment_research_20261115/exploratory_long/diagnostics/experiment.yaml`。
  该数据不足以证明多个互补短段能够独立标定；需要更多同安装配置、
  时钟已审计的采集及独立物理 holdout，才能继续做有效的多段联合比较。

## 2026-11-15 取消旋转和时间研究比较门限

- 根据用户要求，本轮研究比较不再按旋转、时间差及时间窗口偏移离散度
  做阈值判定；平移比较沿用本轮 5 cm。原始差值、旧门限报告及其他
  输入质量诊断保留；未更改 GRIL 的充分性门限和算法。
- 三次完整运行相对 frozen reference 的最大差值：旋转 0.208°、平移
  4.57 cm、时间 0.199 ms。完整运行内部最大重复差分别为 0.066°、
  0.167 cm、0.041 ms；长窗口重复差分别为 0.143°、1.43 cm、0.316 ms。
- 第一轮的四个时间窗口相关峰在完整运行中为 -46/-36/-52/-48 ms，
  在长窗口中为 -46/-38/-48/-52 ms；其符号约定见对应 profile，不等同
  于 GRIL 输出的 time lag。保留这些变化作为诊断，不再按本轮门限拒绝。
- 取消比较门限只允许继续研究，不证明迁移数值等价或外参准确。优先
  补采同安装配置下的独立互补运动和物理验证数据；并行做单段模型与
  退化仿真，之后再验证共享外参的多段优化，不能把重叠窗口当独立证据。
  本轮报告：`outputs/gril/segment_research_20261115/diagnostics/open_rotation_time_review.yaml`。
