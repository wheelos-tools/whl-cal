# LiDAR-IMU 标定目标、系统边界与数学模型

[返回 LiDAR-IMU 方案索引](../lidar2imu.md)

## 一、项目目标与设计边界
### 1.1 需要解决的问题
针对乘用车、园区无人车和其他 Ground Vehicle，车辆运动主要发生在地平面内：
- 主要旋转：绕垂直轴的 Yaw。
- 主要平移：车辆前向、横向。
- Roll、Pitch：通常较小，但不能视为恒定为零。
- Z 向运动：受坡道、道路起伏、悬架和车身姿态影响。
- 传感器安装位置：存在明显的机械安装倾角和杆臂。
- 多个采集 Bag：可能包含不同的运动激励、时间戳基准和 IMU Bias。
普通地面车辆数据无法保证单独提供完整的 6-DoF 外参观测信息。

因此，系统的核心不是强制恢复六个自由度，而是：
1. 最大程度利用正常车辆运动获得可观测参数。
2. 利用地面几何和经过测量的物理先验补足特定自由度。
3. 利用多段互补运动提高标定质量。
4. 对真正不可观测的自由度明确标记。
5. 只有满足精度及独立验证要求时才发布完整标定结果。
### 1.2 第一版明确标定范围
GV-MultiCalib v3.0 / Scope
第一阶段实施范围
参数	是否纳入
LiDAR → IMU 旋转外参	是
LiDAR → IMU 平移外参	是
LiDAR-IMU 时间偏移	是
IMU Gyroscope Bias	是
IMU Accelerometer Bias	是
局部地面法向与高度	是
多段共享外参	是
每段独立连续时间轨迹	是
每段时钟偏移	根据时钟架构决定

Camera 外参	暂不纳入
轮速计、GNSS 联合标定	暂不纳入

第一版的目标是稳定完成 LiDAR-IMU 6-DoF 外参及时间偏移标定，而不是同时解决所有多传感器标定问题。
### 1.3 核心技术原则
确定以下六条不可违反的设计原则：
1. 保留完整 3D SE(3) 轨迹，不采用强制平面化的 SE(2) 轨迹。
2. 不把世界系 Z 向速度恒为零作为车辆运动假设。
3. 不把传感器垂直杆臂视为能够仅靠平面运动自动估计。
4. 不因为参数块拆分就宣称参数之间已经数学解耦。
5. 不将环境几何先验带来的信息误认为车辆运动本身提供的信息。
6. 不允许优化收敛代替可观测性和独立精度验证。

## 二、总体技术架构
GV-MultiCalib
Ground Vehicle Multi-Session Calibration
离线、多段、无靶标、可观测性感知标定


01. Session Data Manager

数据读取、时间戳检查、传感器信息、坐标系管理、多段数据组织。


02A. Geometry Pipeline

地面分割、局部平面、垂直 Surfel、动态点过滤


02B. Motion Pipeline

车辆机动识别、转弯激励、角加速度、时间动态分析




03. Initialization Engine

重力辅助倾角初始化、二维手眼标定、时间互相关、杆臂初值、轨迹初始化。


04. Multi-Session Continuous-Time Optimizer
全局共享：外参、符合时钟架构的公共时间参数
Session 独立：轨迹、Bias、局部重力、必要的时钟参数
联合残差：IMU、LiDAR-Surfel、GPM、Ground Height、Physical Prior
Ceres Solver / SE(3) B-Spline / Sparse Normal Cholesky


05. Observability & Uncertainty Engine

数据可观测性、SVD、边缘化信息矩阵、后验协方差、先验敏感性及退化分析。


06. Independent Validation & Release

独立数据段验证、参数一致性、系统效果验证、质量报告和配置发布。


系统分为六层，前四层负责求解，后两层负责判断求解结果是否可信。

## 三、数学模型与坐标系规范
这一部分是整个项目最重要的基础。后续所有代码必须以本节定义为准，不能由不同模块分别定义转换方向。
### 3.1 统一坐标系
使用自动驾驶常用的 FLU 约定：
坐标系	定义
\(W_k\)	第 k 段数据的局部世界系
\(I_k\)	IMU 坐标系
\(L\)	LiDAR 坐标系
\(B\)	车辆 Base Link 坐标系

车辆坐标系：
- X：前方。
- Y：左方。
- Z：上方。
每一段数据拥有独立的局部世界系：
\[
W_1,W_2,\ldots,W_K
\]

它们不需要具有相同的原点或初始偏航角。

但所有段必须使用同一个传感器安装配置。
### 3.2 外参定义
统一规定：
\[
T_{IL}=
\begin{bmatrix}
R_{IL}&t_{IL}\\
0&1
\end{bmatrix}
\]

它的含义是：
\[
p_I=R_{IL}p_L+t_{IL}
\]

其中：
- \(R_{IL}\)：LiDAR 坐标向量旋转到 IMU 坐标系。
- \(t_{IL}\)：LiDAR 原点在 IMU 坐标系中的位置。
因此：
\[
t_{IL}=
\begin{bmatrix}
p_x\\p_y\\p_z
\end{bmatrix}
\]

注意，\(p_z\) 必须明确为 IMU 坐标系 Z 方向的杆臂分量，不能与世界系高度、车辆离地高度混用。

输出文件同时提供：
\[
T_{LI}=T_{IL}^{-1}
\]

避免下游模块再次猜测转换方向。
### 3.3 连续时间车辆轨迹
每段数据建立独立的 IMU 连续时间轨迹：
\[
T_{W_kI_k}(t)=
\begin{bmatrix}
R_{W_kI_k}(t)&p_{W_kI_k}(t)\\
0&1
\end{bmatrix}
\]

采用连续时间 SE(3) B-Spline。

三次样条的每个时间区间由局部相邻控制点共同决定。

保留：
- 3D 平移。
- Roll。
- Pitch。
- Yaw。
- 一阶导数。
- 二阶导数。
不降为 SE(2)，也不对轨迹施加全局 \(v_z=0\) 的硬约束。

原因是车辆即使主要沿地平面运动，也会受到坡度、横坡、悬架和路面起伏影响。全局水平约束会使真实运动被模型吸收为虚假的传感器外参误差。

局部平坦性由后续的 Ground Motion 因子提供，而不是通过删除轨迹自由度实现。
### 3.4 IMU 运动模型
定义：
\[
\omega_I(t)=
\left(R_{WI}^T(t)\dot R_{WI}(t)\right)^\vee
\]

\[
a_I(t)=R_{IW}(t)
\left(\ddot p_{WI}(t)-g_W\right)
\]

IMU 测量模型：
\[
\omega_m(t)=\omega_I(t)+b_g(t)+n_g
\]

\[
f_m(t)=a_I(t)+b_a(t)+n_a
\]

其中：
- \(b_g\)：陀螺仪 Bias。
- \(b_a\)：加速度计 Bias。
- \(n_g,n_a\)：噪声。
每个 Session 独立估计 Bias，第一版可先采用 Session 内常值 Bias。长时间连续采集再考虑随机游走模型。

世界系 Z 轴与重力方向对齐：
\[
g_{W_k}=[0,0,-g]^T
\]

这样地面可以相对于重力方向具有坡度和横坡，而不会强迫地面法向等于世界系 Z 轴。

## 四、多段联合状态变量设计
这是 GV-MultiCalib 区别于单段 LI-Calib 和 GRIL-Calib 的核心。

定义总优化状态：
\[
\Theta=
\left\{
T_{IL},
\Theta_1,\ldots,\Theta_K
\right\}
\]

全局共享外参：
\[
\Theta_{\mathrm{global}}=
\{R_{IL},t_{IL}\}
\]

第 k 个 Session 的状态：
\[
\Theta_k=
\left\{
C_k,b_{g,k},b_{a,k},g_{W_k},
\delta_k,a_k
\right\}
\]

其中：
状态变量	属性	说明
\(R_{IL}\)	全局共享	LiDAR-IMU 旋转
\(t_{IL}\)	全局共享	LiDAR-IMU 平移
\(C_k\)	每段独立	B-Spline 控制点
\(b_{g,k}\)	每段独立	Gyro Bias
\(b_{a,k}\)	每段独立	Accel Bias
\(g_{W_k}\)	每段局部	重力方向，或通过世界系定义固定
\(\delta_k\)	按时钟架构决定	有效时间偏移
\(a_k\)	可选	时钟频率比例误差

### 4.1 时间偏移模型
定义 LiDAR 时间戳转换到 IMU 时间轴：
\[
\tau_k(t_L)=
t_{0,k}
+a_k(t_L-t_{0,k})
+\delta_k
\]

这里规定 \(\delta_k>0\) 表示 LiDAR 测量对应的 IMU 轨迹查询时间向后移动。

如果两种传感器使用相同稳定硬件时钟：
\[
a_k=1,\quad \delta_k=\delta_{\mathrm{global}}
\]

如果不同 Bag 来自不同上电会话，可能存在独立时间原点：
\[
\delta_k=\delta_{\mathrm{effective},k}
\]

第一版只估计能够从数据中辨识的有效时间偏移，不同时优化一个公共偏移和一个完全自由的 Session 偏移。

因为两者如果没有额外时钟参考，本身无法独立区分。

只有在硬件同步信息明确的情况下，才拆成公共硬件延迟与会话时钟原点。

另外：
- 同一时钟的时间比例 \(a_k\) 默认固定为 1。
- 只有长时间采集显示明显时钟漂移时才开放。
- 不同上电 Session 的实际时间偏移必须独立验证。
LI-Init 的文档明确指出，部分 Livox 设备以开机时间作为时间戳原点，重新上电后偏移可能改变，因此不能一律假设所有 Bag 的时间偏移相同。
参考实现和时钟模型边界见[参考项目对比](06_reference_projects.md)。

### 4.2 Gauge Freedom 处理
每个 Session 使用自己的局部世界系。

建议：
1. 第一帧 IMU 位姿固定为局部参考位姿。
2. 世界系 Z 轴与重力方向一致。
3. 第一帧初始 Yaw 作为局部世界系定义。
4. 每段轨迹控制点仅在本 Session 内优化。
5. 不允许不同 Session 的世界系原点自动相互约束。
这样避免多段联合优化中无意义的世界系自由度。

## 五、车辆运动可观测性与参数估计策略
这是整个方案的核心理论部分。

必须明确：车辆运动、环境几何、人工先验是三种不同的信息来源，不能混在一起评价。
### 5.1 六自由度参数的可观测性
最终需要估计：
\[
\theta=
[
\phi_x,\phi_y,\phi_z,
p_x,p_y,p_z,
\delta
]^T
\]

各参数的信息来源如下：
参数	主要观测来源	典型退化工况
Roll	重力、地面几何、旋转运动	只有单一且不可靠的地面参考
Pitch	重力、地面几何、旋转运动	缺少可信倾角参考
Yaw	水平运动对应关系、手眼标定、环境几何	缺少有效方向信息和几何约束
\(p_x\)	转弯角速度、角加速度、环境几何	纯直线运动
\(p_y\)	转弯角速度、角加速度、环境几何	纯直线运动
\(p_z\)	地面高度、独立物理测量、额外空间激励	纯平面运动且没有高度参考
\(\delta\)	时变角速度、时变加速度、动态运动对应	静止或恒定运动

其中有三个必须牢记的结论。

第一，平面运动下不能仅依靠运动学加速度获得 \(p_z\)。

当车辆只有绕 Z 轴的旋转时：
\[
\omega=
\begin{bmatrix}0\\0\\\omega_z\end{bmatrix}
\]

\[
p=
\begin{bmatrix}p_x\\p_y\\p_z\end{bmatrix}
\]

杆臂诱导加速度中不包含 \(p_z\)：
\[
\frac{\partial a_{\mathrm{lever}}}{\partial p_z}=0
\]

因此，\(p_z\) 需要独立的地面高度约束或物理测量先验。

第二，Yaw 不要求必须通过剧烈转弯才能估计。

有效的二维运动方向对应关系可能提供 Yaw 信息，但前提是两者对应同一个物理参考点，且时间、杆臂和侧滑影响得到处理。

单纯比较两个传感器的 Z 轴角速度：
\[
\omega_{z,I}\approx\omega_{z,L}
\]

不能估计绕 Z 轴的安装角。

第三，水平杆臂不要求必须有剧烈角加速度。

根据刚体运动学，令 \(p\) 为 IMU 原点指向 LiDAR 原点的杆臂，且两者加速度已经转换到同一 IMU 表达坐标系：
\[
\Delta a=
\alpha\times p+
\omega\times(\omega\times p)
\]

在纯 Yaw 旋转下：
\[
\begin{bmatrix}
\Delta a_x\\
\Delta a_y
\end{bmatrix}
=
\begin{bmatrix}
-\omega_z^2 & -\dot{\omega}_z\\
\dot{\omega}_z & -\omega_z^2
\end{bmatrix}
\begin{bmatrix}
p_x\\p_y
\end{bmatrix}
\]

当：
\[
\omega_z\ne0
\]

该理想平面杆臂观测矩阵的行列式为：
\[
\det(J_{p_{xy}})=
\omega_z^4+\dot{\omega}_z^2>0
\]

所以持续转弯也可以提供水平杆臂信息。

但是实际系统还存在 IMU Bias、轨迹误差、噪声和时间偏移耦合，最终必须通过完整系统 Jacobian 验证。
### 5.2 车辆运动数据集的设计
建议建立以下运动数据类别。

A：静止段

作用：Gyro Bias 初值、加速度计 Bias 初值、重力方向。

限制：无法独立确定 Yaw、时间偏移和水平杆臂。

B：直线匀速段

作用：有效速度对应关系、LiDAR 平移轨迹初步验证。

限制：不能提供有效的杆臂旋转诱导信息；恒定速度无法单独确定时间偏移。

C：直线加减速段

作用：动态加速度对应、时间偏移估计、Bias 与加速度模型检查。

限制：不能直接用于求解水平杆臂。

D：S 弯或左右转弯

作用：旋转运动激励、水平杆臂估计、Yaw 与时间参数联合约束。

优先推荐：左右方向不同、曲率变化丰富的连续运动。

E：坡道与横坡段

作用：验证局部地面约束、地面法向变化及垂直方向模型。

限制：坡度本身不保证所有 6-DoF 自动可观。



最低推荐采集组合
建议实际采集时包括：
- 静止开始和结束。
- 变化速度的直线运动。
- 左右方向的转弯。
- 至少一组类似 8 字形的轨迹。
- 足够的稳定地面区域。
- 有一定方向多样性的墙面、立柱或其他静态结构。
GRIL-Calib 的官方文档也建议使用平地和 8 字形采集，并要求提供 IMU 离地高度。但其当前自定义数据版本明确限制在机械旋转式 LiDAR（Velodyne、Ouster），不能直接假设支持所有固态 LiDAR。
参考实现的输入支持边界见[参考项目对比](06_reference_projects.md)。


以上是推荐采集组合，不是必须采集五种数据后才能求解的硬规则。最终是否满足要求，由实际观测矩阵决定。
